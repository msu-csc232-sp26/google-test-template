# Task 1: Define timestamp generator function

When logging information, it is common to output the moment in time the logged information was generated. To that end,
we'll develop a function that will give us the current time as a string in a particular format. For example, consider
the following error logs generated by some service:

```terminaloutput
[2025-08-10 17:40:10] ERROR: Can not open data file.
[2025-08-10 17:40:10] ERROR: Network connection timed out during API call.
```

The error log message begins with a timestamp printed inside a pair of square brackets. Your first task is to define a
function that returns the current date/time as a string in the following format: `YYYY-MM-DD hh:mm:ss`

## The chrono library

The `chrono` library contains functions that provide access to the current date and time. See
the [Date and Time Library](https://en.cppreference.com/w/cpp/chrono.html) on cppreference.com.

Firstly, we need access to a clock. The `chrono` library
provides [clocks](https://en.cppreference.com/w/cpp/chrono.html#Clocks), e.g., `std::chrono::system_clock`. This clock
exposes a method named `now( )` that gives us a [`time_point`](https://en.cppreference.com/w/cpp/chrono/time_point.html)
instance. For example:

```cpp
auto const now = std::chrono::system_clock::now( );
```

Since we just need to _inspect_ the current time from clock, we make the instance a `const` object (meaning, we can't
change it once it is created). Further, it is a (good) standard practice to declare the local instance using `auto` (
which is deduced by the compilation system to be a `time_point` instance).

With a clock in hand, we use it to get another kind of object, and instance of `time_t`. Many date/time functions
operate with instances of `time_t`. To obtain a `time_t` instance of the current time, we use the
`to_time_t( const time_t& )` function:

```cpp
auto const current_time = std::chrono::system_clock::to_time_t( now );
```

Notice we pass the `time_point` reference `now` we obtain previously to the function. The local variable `current_time`
is
now an instance of `time_t` that represents the current point in time.

Another requirement here is that the generated timestamp must be formatted for the _local_ time.
See [localtime](https://en.cppreference.com/w/cpp/chrono/c/localtime) which converts the given time (parameter) since
epoch as `std::time_t` value into calendar time, expressed in local time.
